## What I built

### Backend (`apps/api`)
- **`schemas/account.py`** (new) — `ExportBundle` + per-table row models on the `CamelModel`
  base. Serializes to the frozen `ExportBundle` camelCase shape. Notes:
  - `llmCosts` matches the frozen `LlmCost` interface exactly (`costUsd` a JSON **number**,

## ⚠️ Shared-surface amendment for the integrator (one line, OBS-owned file)
The opt-out **endpoint + column write are fully in-lane and tested.** Enforcing "an opted-out
company is excluded from future ingest" needs a one-line guard in **`services/run.py`**
(`ingest_company`) — that file is **OBS-owned**, so per the playbook I did **not** edit it and
flag it here as a serialized amendment (apply during DATA integration, which follows OBS):

```python
# specula_api/services/run.py, top of ingest_company(...)
company = await session.get(Company, company_id)
if company is None or company.user_id != user_id or company.opt_out:   # <-- add `or company.opt_out`
    return
```

Context: in the current inline architecture there's no re-ingest-existing-companies loop, and
discovery already won't re-stage a known company's domain, so an opted-out company is already
effectively excluded today. The guard above is the defensive enforcement for when a scheduler /
re-ingest path lands. No other lane touches `company.py`.
